# 验证记录

验证日期：2026-10-10。电脑配置见仓库 README。以下是单台电脑上的结果，不代表其他机型或驱动组合兼容。

## 模式与界面

- 用户按一次 Fn+3，窗口从游戏模式变为狂暴模式；直接 EC 查询值从 2 变为 3。
- 优化版运行后，用户确认鼠标旁每秒出现一次的加载图标已经消失。
- 传感器使用原厂 EC 查询协议取得，不以风扇声音或转速阈值推断性能模式。

## 生命周期与异常

| 项目 | 本次结果 |
| --- | --- |
| 连续八次刷新 | 同一个读取进程，只启动一次 |
| 窗口隐藏后观察 3.1 秒 | 读取进程退出，查询次数不再增加 |
| 恢复窗口 | 约 390 ms 返回有效当前状态 |
| 快速最小化与恢复 | 恢复有效读取 |
| EC 查询锁被占用 | 返回未确认；释放后复用同一个进程恢复 |
| 模拟读取进程超时 | 约 2.2 秒停止读取进程，不形成反复启动的重试循环 |

超时测试让测试子进程等待，没有让真实硬件驱动陷入卡死。测试源码在 `tests/LifecycleTest.cs`。

## 内存采样

按私有工作集比较，接近任务管理器常见的“内存”列：

| 状态 | 本次采样 |
| --- | ---: |
| 旧版界面/托盘进程 | 38.19 MiB |
| 优化版界面/托盘进程 | 7.60 MiB |
| 优化版读取进程 | 3.10 MiB |
| 优化版窗口打开时合计 | 10.70 MiB |
| 优化版隐藏到托盘后 | 7.72 MiB，读取进程已退出 |

旧版数值不包含每秒临时启动的读取进程；新版合计包含窗口打开期间保留的读取进程。数值是实测快照，随运行时间、系统状态和 .NET 垃圾回收变化，不是固定上限。程序没有强制清空工作集或定期强制垃圾回收。
